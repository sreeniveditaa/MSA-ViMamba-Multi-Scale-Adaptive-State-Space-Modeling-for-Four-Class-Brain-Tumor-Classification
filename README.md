# MSA-ViMamba-Multi-Scale-Adaptive-State-Space-Modeling-for-Four-Class-Brain-Tumor-Classification

## Abstract

Automated classification of brain tumors from magnetic resonance imaging (MRI) is challenging because diagnostically useful patterns occur at different spatial scales and visually similar tumor categories can share intensity, shape, and anatomical characteristics. This work presents MSA-ViMamba, a compact multi-scale adaptive state-space model for four-class MRI classification into glioma, meningioma, no tumor, and pituitary tumor. The implemented architecture first extracts a 56×56 representation using a convolutional stem and then constructs three 14×14 feature maps that emphasize local, medium-context, and global-context information. An adaptive gating module converts global descriptors of the three maps into normalized image-specific fusion weights. The fused feature map is flattened into 196 spatial tokens of dimension 192 and processed by four residual Mamba blocks. The final embedding is classified using dropout and a four-class linear layer. Experiments used 5,040 training images, 560 validation images, and 1,600 test images. MSA-ViMamba achieved 79.37% test accuracy, 81.75% precision, 79.37% recall, and 78.19% F1-score. Controlled comparisons produced 67.31% for a single-scale Mamba baseline and 76.94% for an equal-weight Multi-Scale Mamba model, supporting the contribution of both multi-scale representation and adaptive fusion. We further inspected representative predictions using Grad-CAM++. The results indicate a feasible state-space direction for brain MRI classification, but also indicate the difficulty of glioma and meningioma discrimination that still persists.
